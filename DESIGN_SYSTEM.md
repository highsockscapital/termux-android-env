# Neo-Brutalist Material 3 Design System

- Window / Background: `#FFFFF0` (Ivory)
- Text Primary & Icons: `#161610` (Dark Charcoal)
- Card Surfaces / Dialogs: `#FFFFFF` (Clean White)
- Accent Color: `#FF9E43` (Soft Light Orange — for FABs, progress bars, active states)
- Strokes & Borders: Apply a solid 1dp or 2dp `#161610` stroke on all Buttons, Cards, Input Boxes, and Dialog borders.
- Status Bar: Matches Window (`#FFFFF0`) with dark status bar icons enabled.
