# termux-android-env

Standard Termux **ARM64** documentation and build templates for **OpenJDK 17** Android projects
using the **Neo-Brutalist Material 3** design palette.

## Docs

- [**ENVIRONMENT.md**](ENVIRONMENT.md) — Termux / PRoot ARM64 build environment rules (JAVA 17,
  AAPT2 override, JVM limits, credentials).
- [**DESIGN_SYSTEM.md**](DESIGN_SYSTEM.md) — Neo-Brutalist Material 3 design system and palette.

## Templates

- [**templates/gradle.properties**](templates/gradle.properties) — standard Gradle build
  settings for Termux ARM64 / OpenJDK 17.
- [**templates/colors.xml**](templates/colors.xml) — Neo-Brutalist color resource (values XML).
